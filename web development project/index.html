Syllabus Highlights

Web Development Concepts Demonstrated

This project satisfies the practical requirements of the BCA Semester I syllabus through rigorous code standards.

Semantic HTML5 Structure

Proper use of semantic landmarks (<header>, <nav>, <main>, <section>, <article>, <footer>) ensuring accessibility and search-friendly markup.

Responsive CSS3 & Flexbox/Grid

Crafted with responsive layouts, CSS Custom Properties (Variables), dark/light mode theming, glassmorphism design, and mobile-friendly media queries.

Interactive Vanilla JavaScript

DOM manipulation, persistent theme toggle with localStorage, animated progress counters, live form validation, and accessible modal popups.
