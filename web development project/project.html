1. Project Abstract & Objectives

The primary objective of this project is to build a modern, high-performance, and fully responsive multi-page student portfolio website. It acts as both a showcase for the academic journeys of two BCA students and a practical demonstration of modern front-end web engineering standards.

Key Syllabus Learning Objectives:

  • Master semantic HTML5 element hierarchy for high accessibility and SEO friendliness.
  • Apply modern CSS3 layout paradigms, including CSS Flexbox and CSS Grid.
  • Implement responsive web design principles supporting mobile, tablet, and widescreen displays.
  • Incorporate custom CSS variables to enable seamless real-time Dark/Light Mode theming with persistence.
  • Demonstrate JavaScript DOM manipulation, event listeners, and client-side form validation.
  • Execute live cloud deployment using GitHub Pages, understanding version control and static web hosting.

3. Step-by-Step Live Deployment Guide

To satisfy the “Live Deployment” criteria of the project title, the website can be deployed live to the internet using GitHub Pages or Vercel/Netlify for zero cost. Follow the steps below during your practical evaluation:

Method A: Deploying with GitHub Pages (Recommended)

1

Initialize Git Repository

Open PowerShell or Terminal in the project directory and initialize a Git repository:

git init git add . git commit -m "Initial commit: BCA Sem 1 Student Profile Website"
2

Create GitHub Repository & Push

Create a new public repository on GitHub.com named student-profile-website, then link and push:

git branch -M main git remote add origin https://github.com/<your-github-username>/student-profile-website.git git push -u origin main
3

Enable GitHub Pages

1. Open your repository on GitHub and click on the Settings tab.
2. On the left sidebar, click on Pages.
3. Under Build and deployment → Branch, select main and folder / (root).
4. Click Save.

4

Access Your Live Website

Within 60 seconds, GitHub Pages compiles the site and provides an active HTTPS live URL:

https://<your-github-username>.github.io/student-profile-website/

The website is now globally accessible on any smartphone, tablet, or PC!

Method B: Instant Drag & Drop via Netlify

1. Visit netlify.com/drop.
2. Simply drag and drop the web development project folder onto the browser window.
3. Netlify will generate an instant live URL (e.g., https://bca-student-profile.netlify.app) in under 10 seconds.

Viva Voce Practical Questions & Answers

Be ready to answer these common questions during your practical viva evaluation:

Q1: Why did you use semantic HTML5 elements?

Semantic tags like <header>, <nav>, <main>, <section>, and <footer> provide meaningful context to web browsers, screen readers, and search engine crawlers, boosting accessibility and SEO compared to non-semantic generic <div> tags.

Q2: How does the Dark / Light Mode theme toggle work?

We define CSS custom properties (variables) on the root element. When the toggle button is clicked, JavaScript updates the data-theme="dark" attribute on the <html> tag and saves the selection in the browser's localStorage, preserving user preference across refreshes.

Q3: How is responsive design achieved without heavy external frameworks?

We used CSS Flexbox, CSS Grid layouts, fluid viewport units (clamp() for responsive fonts), and CSS media queries at 1024px, 768px, and 480px to gracefully adapt layouts from mobile screens to desktop monitors.

Q4: How does client-side validation work in your contact form?

JavaScript listens to input and submit events, applying regular expressions for email validation and checking length requirements. If an error is detected, CSS classes like .is-invalid provide immediate visual feedback before any data is sent.
